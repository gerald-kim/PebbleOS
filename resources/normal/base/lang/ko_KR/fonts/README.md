# Galmuri fonts

This language pack uses Galmuri 2.40.4 by Lee Minseo, distributed under the
SIL Open Font License 1.1. Regular slots use Galmuri9, Galmuri11, and
Galmuri14. Bold slots use the official Galmuri11 Bold face at the matching
pixel height.

- Source: <https://github.com/quiple/galmuri>
- Project page: <https://quiple.dev/font/galmuri>
- License: `LICENSE.txt`

The Korean glyphs are rendered about one visible pixel larger than the first
pack while retaining the baseline of the built-in Pebble Gothic fonts:

| Pebble font | Galmuri source | Pixel height |
|---|---|---:|
| Gothic 14 | Galmuri9 | 11 |
| Gothic 18 | Galmuri11 | 13 |
| Gothic 24 | Galmuri14 | 16 |
| Gothic 28 | Galmuri9 | 21 |
| Gothic 36 | Galmuri11 | 25 |

| Pebble bold font | Galmuri source | Pixel height |
|---|---|---:|
| Gothic 14 Bold | Galmuri11 Bold | 11 |
| Gothic 18 Bold | Galmuri11 Bold | 13 |
| Gothic 24 Bold | Galmuri11 Bold | 16 |
| Gothic 28 Bold | Galmuri11 Bold | 21 |
| Gothic 36 Bold | Galmuri11 Bold | 25 |

Galmuri11 Bold covers every selected modern Hangul syllable. It does not
contain the archaic Hangul compatibility letter U+318D.
